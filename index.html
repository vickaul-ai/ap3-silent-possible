What AP3 ships today

        
Research preview — aligned with ap3-protocol.org. This wireframe may show future operations as modeled manifests.

      

      

        

          Available now
          PSI between ap3_initiator and ap3_receiver; signed commitments, PrivacyIntentDirectives, PrivacyResultDirectives; replay protection.
        

        

          PSI semantics
          Both parties run crypto rounds; only the initiator learns the intersection or count. The receiver does not see the initiator's full query set.
        

        

          On the roadmap
          More operations (threshold, private score, set cardinality), proof-of-computation, receiver-signed receipts, custom operation DSL.
        

      

    


    

      

        
Why AP3 belongs in product design

        
Traditional agent workflows often ask someone to share too much: a full list, a private preference, a raw profile, or a sensitive file. AP3 narrows that exchange to compatibility, intent, privacy-preserving computation, and verifiable output.

      

      

        

          
Without AP3

          
Agents coordinate by sending raw context, broad permissions, private lists, or sensitive documents into shared conversation state. The workflow works, but the privacy boundary collapses.

        

        

          
With AP3

          
Agents advertise roles and commitments, accept signed purpose-bound directives, run an approved private operation, and reveal only the result the user or counterparty agreed to receive.

OpenClaw / Hermes implementation view

        
This is still a wireframe, but the component map follows the AP3 vocabulary: AgentCards, roles, commitments, directives, private operations, result directives, and evidence bundles.

      

      

        

          

            

              
Agent state stays local

              
OpenClaw or Hermes stores household norms, preferences, care constraints, or enterprise records in local memory. The AP3 surface sees tags, commitments, or operation inputs only after owner policy approval.

            

          

          

            

              
AgentCard declares capability

              
Each agent advertises compatible roles, supported operations, commitment shape, freshness, and public verification keys before private data enters a session.

            

          

          

            

              
PrivacyIntentDirective opens the session

              
The directive binds purpose, participants, expiry, replay nonce, allowed output, and payload hash. The receiver checks it before touching the cryptographic payload.

            

          

          

            

              
Private operation returns minimal output

              
The demo treats PSI as the first concrete primitive and represents threshold reveal, secure dot product, and private scoring as planned operation manifests.

            

          

          

            

              
Evidence becomes the product surface

              
Users, auditors, and counterparties see signed directives, result receipts, compatibility checks, and policy decisions, not raw private inputs.

            

          

        


        

          

            
            
            
            
          

          

        

      

    


    

      

        
Evidence bundle wireframe

        
The AP3 result is intentionally small. The trust story lives in the evidence around that result.

      

      

        
Signed intentPurpose, participants, expiry, operation, replay nonce, payload binding.

        
Compatibility checkRoles complement, operation match, commitment shape, receiver public key.

        
Compute transcriptRound IDs, payload hashes, session binding, receiver checks, timeout status.

        
Result directiveMinimal output, integrity hash, result recipient, signature, metadata.

        
Policy logAllowed fields, forbidden actions, query budget, threshold, consent record.

        
Settlement hookOptional AP2 or x402 step after a verifiable result is available.
